# Mesa STPS Selectas

Escritorio compartido entre ChatGPT (cuenta personal) y Cursor (cuenta de trabajo).

Los originales están solo en la computadora de la empresa: `C:\Users\Usuario\Desktop\STPS`.
Este repositorio no lleva INE, nómina, IMSS, firmas ni PDF.

## Quién hace qué

- ChatGPT redacta, arma la matriz y corrige. Lee `00_MESA_DE_TRABAJO.md` y escribe en `borradores/`.
- Cursor verifica contra los originales y anota el resultado en `ESTADO.md`.
- Una medida que la mesa marca pendiente no se cierra con una firma, un formato vacío o una plática que no se haya dado.
